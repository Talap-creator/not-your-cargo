# Возможности iDos Games и выбор масштаба игры

Проверено 2026-10-06. Вывод: iDos не ограничен кликерами и мини-играми. Это платформа с host shell, сервисами, AI-инструментами и подключаемыми игровыми модулями. Сам бой/мир может рисоваться Phaser, Three или собственным renderer. Качество результата не гарантируется наличием шаблона.

Это проверка публичных документов и опубликованных контрактов, без запуска production-игры на аккаунте пользователя. Пределы производительности и аккаунтные квоты пока не измерены.

## 1. Что подтверждено

| Возможность | Проверенное основание | Граница вывода |
|---|---|---|
| Собственные 2D/3D-сцены | README и EngineScene в @idosgames/module-sdk 0.10.0: Three/Phaser/custom; lifecycle mount/activate/suspend/destroy | Контракт позволяет сцену, но не обещает её FPS |
| Независимая логика игры | @idosgames/core 0.21.2 описан как engine-agnostic; отдельные game modules в registry | SDK не пишет автоматически баланс и интересный игровой цикл |
| Более объёмные шаблоны | Публично перечислены VoxelCraft, 3D Board Game, Idle RPG и Mini-game; voxelcraft.json присутствует в @idosgames/mcp 0.1.28 | Шаблон не доказывает качество или размер финальной игры |
| Своя web-сборка | Документация загрузки указывает Vite и Unity WebGL; требуется реальная сборка, а не iframe другого сайта | Загрузка Unity не доказывает доступность всех native-функций Unity |
| Игровые сервисы | Каталог iDos содержит профиль, инвентарь, магазин, задания, рейтинг и другие системы | Каждую нужную систему нужно конфигурировать и проверять |
| Реальное сетевое соединение | multiplayer-realtime в опубликованном Code MCP: комнаты, signaling, WebRTC DataChannels, смена host | Это не автоматически серверный симулятор боя и не готовый античит |
| Серверные обработчики | Каталог документирует CloudCode | Не подтверждены длительность обработчика, tick rate, масштаб и пригодность для постоянного игрового сервера |

Пакеты скачаны из npm для чтения; их CLI и install-скрипты не запускались. Указанный в metadata GitHub SDK вернул 404; это не доказательство отсутствия SDK: опубликованные npm-пакеты доступны. Версии — снимок дня исследования, не вечные latest.

## 2. Какие игры можно рассматривать

Ниже инженерные выводы из контрактов, а не каталог гарантированно поддерживаемых жанров.

| Тип проекта | Почему реалистично рассматривать | Что потребуется сверх scaffold |
|---|---|---|
| 2D survival / bullet hell / roguelite | Собственная Phaser-сцена, пулы врагов и оружия | Бой, генерация волн, баланс, удобство |
| Платформер или небольшой metroidvania | Модуль сцены не ограничивает камеры и уровни | Коллизии, уровни, сохранение, большой объём контента |
| Карточная тактика / пошаговая стратегия | UI и игровые данные отделены от renderer | Правила, AI противника, проверка ходов |
| Tycoon / idle / ферма | Есть игровые сервисы и соответствующие шаблоны | Экономика, расписания, защита операций |
| Небольшая 3D-арена или гонка | Three-сцена либо web-сборка другого инструмента | Физика, камера, оптимизация, мобильный input |
| Воксельная песочница | Есть исходный VoxelCraft-модуль | Генерация/сохранение мира, память, проверка сетевой игры |
| Небольшой кооператив | WebRTC и комнаты | Синхронизация, реконнект, host migration, тесты связи |

Выбранный NOT YOUR CARGO использует эти возможности для кампании и частного PvP. Предыдущая двухминутная аркада была предложена как малый объём для проверки, а не как потолок iDos.

## 3. Что нельзя обещать по этим данным

Нельзя объявить поддержку «100 игроков», «открытого мира любого размера», конкурентного FPS уровня CS, MMO или AAA только потому, что есть Three и Multiplayer. Также нельзя утверждать, что такие проекты запрещены: подтверждённого общего запрета не найдено.

Практические ограничения:

- Браузер: память, GPU, стартовая загрузка, фон вкладки, input, особенности мобильного WebGL. Проверять на устройствах целевой аудитории.
- Сеть: peer-to-peer транспорт не решает доверие к результатам и состояние мира сам по себе. Большие комнаты увеличивают нагрузку, но точный допустимый размер не установлен.
- Платформа: максимальная сборка, хранилище, стоимость запросов/генераций, квоты Title, CloudCode и TURN требуют актуальных параметров аккаунта.
- Производство: ассеты, анимация, дизайн уровней, баланс и QA потребуют работы даже при генерации ИИ.
- Конкурс: сложность не заменяет обязательные материалы, Solana и допуск Colosseum.

Документ не устанавливает числовой «максимум игры»: официального общего потолка по жанру, площади мира или числу сущностей в изученных материалах нет. Это пробел доказательств, не заявление «без ограничений».

## 4. Три проверки перед расширением проекта

### P0. Базовый модуль — максимум 60 минут как бюджет исследования

Из Code MCP взять текущую основу, добавить простую игровую сцену и корректный lifecycle. Пройти вход → игра → lobby → игра 20 раз; проверить suspend и destroy. Зафиксировать версии и команды. Если локальный запуск не получен за это время, назвать зависимость и пересмотреть срок; 60 минут — лимит попытки, не гарантия успеха.

### P1. Реальная загрузка и игровой input

После отдельного разрешения владельца загрузить сборку в нужный Title, проверить её в карточке iDos: клавиатура, touch, звук, переходы, кошелёк, ошибки. Записать максимальный размер сборки/тариф, если интерфейс его сообщает. Не подменять этот результат localhost. Если Title требует выпуск и средств недостаточно, этот тест остаётся заблокированным, локальная разработка может продолжаться.

### P2. Нагрузка

На выбранном ПК и телефоне прогнать 2 минуты с 30 врагами, 180 снарядами и 80 частицами. Замерить средний FPS, p95 времени кадра, память/утечки и задержку input. Это нагрузка нашего ТЗ, не лимит iDos. При просадке сначала оптимизировать пулы и эффекты, затем уменьшить одновременно видимые объекты. Для NOT YOUR CARGO обязательный сетевой прототип двух клиентов проводится до расширения кампании; исходное исследование SDK не подтверждает его работоспособность.

До прохождения P0–P2 нельзя обещать performance для финальной сцены или сроки масштабного 3D-проекта.

## 5. Как сделать короткую игру интереснее

Для выбранного NOT YOUR CARGO: независимое движение и прицел, огонь, рывок и груз. Глубину дают маршруты, укрытия, оружие и необходимость доставить посылку вместо подсчёта убийств. Первый прототип — одна доставка и частная дуэль двух реальных клиентов.

После успешной проверки прототипа реализуются остальные четыре обязательные миссии кампании. Дополнительные режимы/карты и системы аккаунта выходят за MVP. Большой список систем не является доказательством интереса.

Не переводить проект в 3D только потому, что оно доступно. Если визуальная концепция требует 3D, сначала отдельная сцена на 30 секунд с input и нагрузкой, потом решение о смене renderer.
