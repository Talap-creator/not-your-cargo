# NOT YOUR CARGO / «Груз не ваш»

**Довези груз сквозь засаду. Потом перехвати его у друга.**

Браузерный 2D-шутер с видом сверху на iDos Games: кампания из пяти миссий и настоящая сетевая дуэль 1×1 за один груз. Токен Solana **NYCARGO** даёт только косметику — для игры он не нужен.

- Играть: https://idosgames.com/app/QA0X2DY9/
- Токен: `5RWFPAucUS9h4bx1ApTftAWc87jVMxzPTkZwVHSeidos` (Solana mainnet)

**Кампания:** история → полигон → пять контрактов по 2–4 минуты (доставка в три рейса, засада с выбором дороги, конвой, станция в темноте, босс-перехватчик), три сложности, звёзды, четыре оружия, 24 достижения.

**PvP:** комната по коду, выбор оружия, один груз на арене, побеждает первый с тремя доставками; таймер 4 минуты, внезапная смерть, реванш. Это матч двух людей через комнаты iDos и WebRTC, не бот.

**Токен:** облик «Степной след» держателям от 1 NYCARGO (баланс кошелька, подтверждённого подписью, читается из блокчейна), кейсы с покраской байка за NYCARGO (крутит сервер iDos), NFT-сувениры за достижения (выпускает сам игрок). На бой ничего не влияет.
